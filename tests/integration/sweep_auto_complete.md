# T-19 자동 완료 스윕 검증

기준: T-18 PR #47 병합 후 `dev`, Architecture 2-1절·ADR-0006·ADR-0004.
T-18의 `0011` 및 회귀 테스트는 선행 PR에서 병합됐다. 이 브랜치는 0012와 T-19 검증을 추가한다.

## 구현

`0012_sweep_auto_complete.sql`은 `sweep_order_timeouts`를 확장한다.
기존 미입금 만료를 유지하고, `auto_complete.enabled=true`일 때만
`cooking_started_at + N분 <= p_now`인 조리중 주문을 완료한다.
기본 OFF, ON 상태에서 minutes 미설정 시 15분, 허용 범위 1~120분이다.
설정은 매 호출마다 읽는다. 상태 변경·시각·이력은 실제 `transition_order`에 위임한다.
행 잠금과 SKIP LOCKED를 사용하며 CAS 충돌만 건너뛰고 나머지 오류는 전파한다.
함수 호출 권한은 기존과 같이 service_role로 제한한다.
