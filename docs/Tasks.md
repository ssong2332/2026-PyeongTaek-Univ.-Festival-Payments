## 상태 판정표

| 상태 | 의미 | 전환 주체·시점 |
|---|---|---|
| 대기 | 착수 전 | 초기값 (작업 생성 시) |
| 진행 | 구현 중 | 팀장이 작업 착수 승인 시 |
| 검증중 | 리뷰/QA 단계 | 팀원이 "검증 전환 요청"(구현 근거 첨부)을 보고하고 팀장이 확인 시 |
| 완료 | DefinitionOfDone 전부 통과 + 근거 기록됨 | 팀장이 리뷰·QA 통과 확인 뒤 |
| 보류 | 팀장 결정 대기 (Open Question 번호 기재) | 팀장 |

상태 전환은 전부 팀장만 수행한다 — 팀원은 요청·보고로만 관여한다.

완료 판정은 임의로 하지 않는다 — 근거 열이 비어 있으면 완료로 표시 금지.

이미 "완료"된 작업의 구현을 바꿔야 하는 경우(진행 중 요구사항 변경 등) 그 행을 되돌리지 않는다 — 새 작업(T-xx)을 만들어 리뷰·QA를 다시 거친다.
