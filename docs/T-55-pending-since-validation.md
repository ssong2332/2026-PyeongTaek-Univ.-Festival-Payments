응답 칸·변환 코드(`pendingSince`, 고객 `toUtcIsoString`)는 #159에서 이미 `dev`에 있다. 관리자 응답은 다른 관리자 시각 칸과 같이 DB 문자열(ISO 8601 UTC, `+00:00`)을 그대로 쓴다 — 팀장 지시(#159·#155)의 `…Z`는 고객 상태 API 대상이고, Architecture "API 공통"의 "시각은 ISO 8601 UTC 문자열"을 따른다.
