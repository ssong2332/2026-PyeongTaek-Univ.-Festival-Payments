# ADR-0005: 다국어 — UI 문자열은 자체 JSON 사전, 메뉴·옵션명은 번역 테이블

> 상태: 승인 (2026-09-22, 사용자)
> 날짜: 2026-09-22

## 맥락

F-05(고객 화면 UI 문자열·메뉴명·옵션명 ko/en 전환, 누락 시 ko 폴백, 언어 추가는 데이터 행 추가만), N-08. 관리자 화면은 한국어 고정(PRD 화면 절에 관리자 다국어 요구 없음). 개발 기간 12일, 프론트 경험 중.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| A. `next-intl` (App Router 표준 라이브러리) | ICU 메시지·복수형·날짜 포맷 내장, 문서 풍부 | `[locale]` 세그먼트 라우팅 또는 미들웨어 설정 필요 — QR URL이 `/ko/...`로 바뀌거나 미들웨어 조합이 늘어남. 버전별 설정 차이로 AI 도구 생성 코드가 어긋나기 쉬움 |
| B. 자체 사전: `messages/ko.json`·`messages/en.json` + `useT()` 훅(키 → 문자열, `{name}` 치환) + 쿠키 `lang` | 의존성 0, 코드 약 40줄, 라우팅 불변(QR URL 그대로), 폴백 규칙을 직접 통제 | 복수형·ICU 없음 — 이 프로젝트 문자열(라벨·안내문) 범위에선 불필요 |
| C. `react-i18next` | 범용, 익숙한 팀 있음 | SSR 초기화 보일러플레이트, App Router 서버 컴포넌트와 조합 시 설정 부담 |

메뉴·옵션명(데이터) 구조는 별도 선택:

| 대안 | 장점 | 단점 |
|---|---|---|
| D1. 컬럼 확장 `name_ko`, `name_en` | 쿼리 단순 | 언어 추가 = 스키마 변경 → N-08 위반 |
| D2. 엔티티별 번역 테이블 `menu_item_translations(menu_item_id, locale, name)` 등 3개 | FK·CASCADE 명확, 타입 생성 시 명확, 언어 추가 = 행 추가 | 테이블 3개 |
| D3. 범용 `translations(entity_type, entity_id, locale, field, value)` | 테이블 1개 | FK 불가, 타입 약함, 조회 조립 복잡 |

## 결정

**UI = B, 데이터 = D2.** 결정적 이유: QR에 인쇄될 URL을 라우팅 변경 없이 유지하고, 팀이 디버깅할 표면(라이브러리 설정)을 없앤다. 데이터는 FK가 있는 D2가 시드·관리 화면(F-27 ko/en 수정) 구현에 가장 명확하다.

규격:
- 언어 결정 순서: 쿼리 `?lang=en` → 쿠키 `lang` → 기본 `ko`. `?lang=`이 오면 쿠키를 갱신(QR에 `?lang=en` 버전을 찍을 수 있음). 언어 토글(`LanguageToggle`)은 쿠키를 바꾸고 `router.refresh()`.
- 지원 언어 목록은 `src/domain/i18n/locales.ts`의 `SUPPORTED_LOCALES = ['ko','en'] as const` + `DEFAULT_LOCALE = 'ko'` — 새 언어 추가 시 이 배열에 코드 1개 추가 + `messages/{code}.json` + 번역 행 추가(코드 로직 변경 없음).
- 폴백: `t(key)`는 현재 언어 → ko → 키 문자열 순. 메뉴·옵션 조회 API는 `COALESCE(요청 언어 행, ko 행)`으로 이름을 채워 빈 문자열 0건(F-05).
- 번역 테이블: `menu_item_translations`, `option_group_translations`, `option_translations` — PK `(entity_id, locale)`, `name text NOT NULL CHECK (length(name) > 0)`. ko 행은 필수(시드 테스트 T-36에서 검증).
- 관리자 화면은 ko 고정(`messages/ko.json`의 `admin.*` 키 사용 — 나중에 en을 추가해도 구조 변경 없음).

## 결과 (트레이드오프 포함)

- 얻는 것: 라우팅·미들웨어 변경 없음, 언어 추가 비용 = 데이터만.
- 감수하는 것: 복수형("1 item"/"2 items")은 키 2개로 처리한다(`cart.count_one`, `cart.count_other`). 날짜·통화 포맷은 `Intl.NumberFormat('ko-KR')`/`Intl.DateTimeFormat`를 `src/lib/format.ts`에 모아 쓴다.
